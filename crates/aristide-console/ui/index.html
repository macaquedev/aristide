Preferences

Instrument

This instrument was combined ad hoc from the sets given on the command line and doesn't live in a file of its own yet. Give a manual a wider compass below if it needs one, then save the combination so it loads the same way next time.

Manuals & compass

A manual can be told to reach further than its sample set's own keys; the extra notes are filled in by repitching the nearest pipe. Native goes back to what the set declares.

Stops

Stops are grouped by the manual their division plays from. Move one to another manual if the combination calls for it.

Couplers

Unchecking takes a coupler off the console without deleting it — the rail simply stops showing it until it's checked again. That's different from the rail's own tablet, which only engages a coupler that's already on the console.

Manuals

Give each of this organ's manuals a keyboard to listen to. Press Listen, then play your keyboard's lowest key and its highest: that names the port and channel, and measures how wide the keyboard is. Keys it reaches past the sample set's own compass are filled in by repitching the nearest pipe; keys outside it stay silent. Assignments are kept per organ.

No manual has an input — this organ will not sound from MIDI until you give one a keyboard.

Detected inputs

The MIDI inputs this machine can see. A manual can listen to a keyboard that isn't plugged in yet; it simply stays quiet.

Bindings

Any MIDI message or computer key can be bound to anything the console can do — draw a stop, work a coupler, nudge the pitch, silence everything. A message bound this way does not also play a note. Bindings are kept per organ, the same as manual assignments.

Temperament & pitch

A division marked • has its own temperament and pitch, apart from the instrument. Everything below reads and sets whichever one is picked above.

Transpose 0

Transposition shifts the keys, not the pipes: the organ keeps its own pitch and temperament.

Room & mechanism

Noises

Blower, drawstop and coupler noises come from the set's own recordings — they sound only where the sample set provides them.
