Inputs

Every input plays the manual its MIDI channel selects below. Pin a device to one manual instead when it speaks on a single channel — two ordinary keyboards then become two manuals.

Channel map

Which manual each MIDI channel plays. Devices set to follow channel map obey this; pinned devices ignore it.

Temperament & pitch

TRANSPOSE 0

Transposition shifts the keys, not the pipes: the organ keeps its own pitch and temperament.

Room & mechanism

NOISES

Blower, drawstop and coupler noises come from the set's own recordings — they sound only where the sample set provides them.
